# 🌐 Jaringan Komputer — Kelompok 4

Website sederhana untuk mengakses sumber pembelajaran **Jaringan Komputer**.

**TKJ SMKN 2 Banjar**

## ✨ Fitur

- Tampilan responsif untuk HP dan komputer
- Desain dark blue dengan efek glow
- Card untuk dua sumber pembelajaran
- Tombol akses Telkom University
- Tombol video YouTube
- Animasi sederhana
- Tidak membutuhkan database, framework, atau backend

## 📁 Struktur Project

```text
jaringan-komputer/
├── index.html
└── README.md
```

## 🚀 Menjalankan di Komputer

Cukup buka file:

```text
index.html
```

menggunakan browser.

## 📦 Upload ke GitHub

1. Buat repository baru di GitHub.
2. Upload `index.html` dan `README.md`.
3. Pastikan `index.html` berada di folder utama repository.

## ▲ Deploy ke Vercel

1. Login ke Vercel.
2. Pilih **Add New → Project**.
3. Import repository GitHub ini.
4. Untuk project HTML statis, tidak perlu build command.
5. Klik **Deploy**.
6. Setelah selesai, Vercel akan memberikan URL website.
